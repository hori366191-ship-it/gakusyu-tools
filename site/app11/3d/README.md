# app11 3D — 球ビュー（公開版）

427 物質すべてを **1 つの球**の上に置き、分野を近い範囲にまとめて眺める
`app11`（有機反応マップ）の 3D 表示です。2D の全体マップは `../`、通常＋大学レベルの
反応を常に合成して表示します（層の切り替えはありません）。

- 公開 URL: `https://hori366191-ship-it.github.io/gakusyu-tools/app11/3d/`
- ローカル: リポジトリのルートで `python -m http.server 8000`
  → `http://localhost:8000/site/app11/3d/`

（Pages 配信からも除外されます）。

## 主な挙動

- 球の外 / 中を下部ツールバー（`I`）で切替。外は距離一定でオービット、中は中心固定で
  視線と FOV のみ。切り替えは短いフェード（`prefers-reduced-motion` では即時）。
- 球面の分野テリトリー（427 スロットの最近傍ボロノイ）を、カード・経路より奥に
  半透明で敷く。境界は異なる分野の間にだけ、低彩度の細い実線＋弱いグロー。
  分類フィルタ中はその分野の面と境界だけ、選択中はさらに薄く表示する。
  球の外では手前半球（シルエット円でクリップ）、球の中では視線の前だけを描く。
  形状は起動時に一度だけ構築し、毎フレームは投影と可視判定だけを行う。
- ドラッグは「指の下の球面を掴む」操作（マウス / 1本指共通）。2本指はピンチのみ。
- 選択中は投影できる裏半球の反応相手も通常カード。画面外・パネル裏・カメラの後ろだけを
  縁の名前付き仮想カードと破線（必要なときは直交ジョグ）で補います。
- 選択解除は、直前に見えていなかったノード・辺だけを約 900ms でフェードイン。
- 詳細ドックは地図の実表示領域の縦横比で bottom / right を決めます（画面幅ではありません）。
- 反応式カードは初期状態でパネル幅に収まり、各カードの「拡大」でだけ横スクロール。
- ビルダーリンク（`detail.js` の `../../app10/`）はこの階層から正しく解決されます。

## テリトリー形状の近似（`sphere-territory.js`）

- 母点は 427 個の固定スロット。球面ボロノイを測地メッシュ（icosphere、
  `subdivision=5` で 20480 面）上の最近傍割当で近似する。面の所属は 3 頂点が
  同分野ならその分野、またがる面は面重心の最近傍。境界は分野が変わる辺の中点を
  結ぶため、真の等距離曲線ではなくメッシュ解像度の折れ線になる。
- 球の外の可視判定は面重心の前後（手前半球）で行い、シルエットは投影した円で
  Canvas がクリップする。円の縁の 1 面ぶんは前後どちらにも寄りうる。
- 球の中では near 面をまたぐ三角形だけカメラ空間で近平面クリップし、視野の外は
  スクリーン矩形で落とす。裏側（視線の後ろ）のテリトリーは描かない。
- 座標・割当・境界は乱数を使わず、同じ `layout` からは常に同じ結果になる
  （`scripts/tests/app11-3d-sphere-territory.test.cjs` で検証）。
