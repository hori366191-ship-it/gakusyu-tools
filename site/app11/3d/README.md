# app11/3d — 有機反応マップ 3D（公開）

`site/app11/3d/` は、有機反応マップ（`site/app11/`）の宣言データを使った **3D 表示の公開ページ**です。
2D 画面の「アカデミック」から移動します。

> 座標データについて: 3D は 2D 用の `site/app11/academic-data.js`（`x / y / label / edges` を含む）を
> **読みません**。`scripts/app11/build-3d-academic-facts.cjs` が作る座標なしの事実データ
> （`academic-facts.js`）だけを使います。Pages の配信物は
> `scripts/app11/build-pages-staging.cjs` が `site/` から組み立て、2D 用の学術配置データは
> 配信物に含めません（リポジトリ内のローカル実験用には残します）。

## 何をする画面か

- 427 物質（`data.js`）を、既存の 2D 配置（`compound.x / y`）から **XZ 平面**へ写し、
  分野（`regionIndex`）・層（`tier`）・接続度・ID ハッシュから **Y（高さ）** を決めて 3D 配置します。
- 通常反応（162）と大学レベルの追加反応（152）を **常に合わせて** 表示します（合成 308 グループ）。
  層の切替 UI はありません（`L` キーも無効）。
- 反応は `site/app11/reaction-groups.js` で重複グループ化し、向きは **基質 → 生成物** に固定します。
  逆向きは別グループです。
- 物質カード・点は 427 件すべてを描画対象にします。未接続の物質も検索・選択・フォーカスできます。
- 検索は名前・別名・示性式・ID の部分一致。検索中は一致物質に加えて、
  **可視層の反応で直接つながる基質・生成物も文脈カード**として残します（推移的な
  波及はしません。多端点の反応は参加する端点をすべて出します）。一致カードは
  シアン枠、文脈カードは淡い枠で区別し、連結経路は減光しません。無関係の物質は
  従来どおり暗い点です。
- 検索結果から選択した場合は、検索表示・query を閉じて選択フォーカスへ切り替えます。
  他の一致が残っていても、表示は選択物質の直接関係グラフだけです。選択解除でも
  query を閉じるため、通常の全物質表示へ戻ります。選択中に検索欄へ入力すると
  選択を解除し、通常の検索（未選択の暗い点）へ戻ります。
- 物質を選ぶと **選択フォーカス表示** になります。表示するのは「選択物質 + 選択物質が
  属する直接関係の反応グループの全基質・生成物」だけで、多端点の反応は参加する端点を
  すべて残します。経路もそれらグループのエッジだけです。無関係の物質は暗い点も含めて
  完全に消え、ヒット対象にもなりません。孤立物質を選ぶとそれ自身だけが出ます。
  選択解除（または検索入力）で全物質・全経路の通常表示へ戻ります。
  選択パネルに構造式（共有 `site/shared/organic-structure.js`）・条件・経路一覧を出します。

## 操作

| 操作 | 動作 |
|---|---|
| 左ドラッグ | オービット（視点回転） |
| 右ドラッグ / Shift+ドラッグ | パン（平行移動） |
| ホイール | カーソル位置を固定してズーム（画面中央固定ではない） |
| ピンチ | ズーム（中点基準） |
| 1 本指ドラッグ（移動） | パン（初期値） |
| 1 本指ドラッグ（回転） | オービット（上下で仰角も変化） |
| 1 本指の「移動 / 回転」 | ツールバーのトグルで切替（狭い画面で表示） |
| 2 本指 | ピンチズーム + 中点移動（両モード共通）。ひねりでは回転しない |
| 矢印キー / `W A S D` | カメラの平行移動（←/A=左、→/D=右、↑/W=上、↓/S=下。固定した地図は逆方向へ流れる。ズーム・前後移動ではない） |
| Shift+矢印キー / Shift+WASD | オービット（従来の向き） |
| `+` / `-` | ズーム |
| `R` / `0` | 初期位置（起動時と同じ最大ズーム・地図中心・元の向き。選択/検索も解除） |
| `F` | 選択物質へフォーカス（明示的なカメラジャンプ） |
| `U` | 未接続の物質を強調 |
| `/` | 検索へ移動 |
| `Esc` | 検索結果・選択を閉じる |

選択（キャンバス・検索・キーボード・候補リストのどれでも）では、カードのアンカーを
**詳細パネルに隠れない実表示領域の中心**へ寄せます。ズーム（カメラ距離）は変えません。
選択以外の操作（層切替・検索入力・未接続強調）ではカメラを動かしません。
選択後に手動でパン／回転／ズームした場合は、リサイズや詳細のレイアウト確定が起きても
勝手に寄せ直しません（まだ中心にある場合だけ補正）。ジェスチャ中も寄せ直しません。

初期位置（`R` / `0`）と選択への移動（`F`）だけが明示的なカメラジャンプです。

#### 起動時ズームと初期位置

- 起動時だけ **対応する最小距離（`MIN_DISTANCE` = 8、最大ズーム）** で地図中心へ置きます。
  ラベルが全部重なって見えないよう、最初から近景の名前だけを見せます。
- 中心付近に実在カードが無い場合だけ、地図中心に最も近い実在物質を「透明なアンカー」に
  して同じ距離で中心へ置きます（選択・詳細は開かない。距離は下げない）。
  実データ（1440×900 / 390×844）では geometric center 付近にカードがあるため
  **fallback は発動せず**、アンカーは layout center `(13.53, 0.04, −16.97)`、
  最寄り物質は `anisole`（中心から 2.94 world）でした。
- `R` / `0` / ツールバーの **「初期位置」** は、起動時とまったく同じ initializer で
  最大ズーム・地図中心・元の向きへ戻します。選択・検索・フォーカス固定・検索表示は
  先に解除して全物質を表示し、現在の見えているポーズから約 520ms で滑らかに遷移します
  （方位は最短回り、距離は正の対数スケール、仰角は範囲内）。`prefers-reduced-motion`
  では即時。遷移中に新しい回転/ズーム/パン/選択があれば、その時点のポーズから
  その操作を優先して遷移を打ち切ります。**初回ページロードだけは遷移せず、直接
  初期ポーズで開始**します。全体像は手動でズームアウトして見ます。
- リサイズ・パネル開閉で勝手に距離を変える処理はありません（固定中のみ pivot 追従）。

#### 選択時のプレビュー + イージング

- 選択（カード・検索結果・キーボード/リスト）では、まず **直前のカメラポーズのまま**
  選択・関係グラフ・詳細を表示し、約 **130ms** プレビューした後、**約 430ms** で
  選択点を usableRect の中心へ寄せます。向き・距離（ズーム）は変えません。
- 既存の単一 rAF コアレス描画に相乗りし、遷移中だけ次フレームを予約します。
  アイドル時のループはありません。`prefers-reduced-motion` ではプレビューせず即時着地。
- 遷移中の新しい選択は「今描かれている補間ポーズ」を開始点にします。解除は遷移を止める
  だけでカメラを戻しません。明示的な回転/ズームは着地後にまとめて適用（キュー）し、
  勝手なジャンプを起こしません。リサイズ/再レイアウトは進行中の遷移を新しい中心へ
  滑らかに振り直します。
- 単一検索結果の一時固定も同じ遷移を使います。入力中は毎キーで動かさず、単一一致が
  変わったときだけ 220ms 待ってから 1 回だけ遷移します。

#### フォーカス固定（選択・単一検索）

- 物質を選ぶと、その world 点を **live な usableRect（詳細パネル等を除いた領域）の中心**に
  固定します。オービット（ドラッグ / Shift+矢印 / 1本指回転）とズーム（ホイール /
  `+` `-` / ボタン / ピンチ）はすべてこの点を軸にし、固定点は中心から動きません。
- 固定中はパン入力（矢印/WASD、右/Shift ドラッグ、2 本指の中点移動）をすべて無効化します。
  進行中のキーボード平滑化も固定開始・解除で停止します。
- 1 本指タッチは固定中つねに回転です。ツールバーの「1本指: 移動」は無効化され、
  解除すると選択してあった移動/回転モードへ戻ります。
- 検索が **実一致 1 件だけ** に絞られた場合も、選択・詳細を開かず同じ固定を一時適用します
  （query・検索結果・文脈表示は保持）。複数一致・0 件では通常表示のままです。
  「名前の完全一致が 1 件」ではなく「実際の一致が 1 件」を条件にしています。
- 固定解除（選択解除・Esc・検索クリア）はカメラを書き換えません。向き・倍率・位置は
  そのままで、自由モードのパン/ズームが再び使えます。`R` / `0`（初期位置）だけは
  選択・検索・固定を解除し、同じ initializer の初期ポーズへ滑らかに戻します。
- 詳細パネルの高さ確定・viewport リサイズ時は、固定点を新しい usableRect の中心へ
  追従させます（固定中はパンが無いため、常に再センタリングしてよい）。

キーボードのパンは **カメラ（観測者）の平行移動** です。←/A はカメラが左へ動くので
固定した地図は右へ流れ、↑/W はカメラが上へ動くので地図は下へ流れます（上下左右とも
画面空間で判定）。前後移動・ズーム・オービットはしません。押した瞬間の 1 タップ（46px）と
保持中の移動を短いイージングで滑らかにし、OS のキーリピートには依存しません。
止まったら描画フレームの予約も止まります。
キーを離す・ウィンドウが blur する・入力欄へフォーカスする・ポインタ操作や選択を始める、
のいずれかでキャンセルされます。`prefers-reduced-motion: reduce` ではイージングせず
1 キーごとに即時移動します（保持中は OS リピートで進みます）。ポインタのドラッグと
Shift+矢印のオービットは従来どおりです。

## 設計上の選択

### Three.js を使わない理由

- 目的は「3D の奥行き」と「読みやすい正面カード」であり、メッシュ・ライティング・
  ポストエフェクトは不要です。
- 依存を増やさず、**Canvas 2D + 透視投影**で実装しました。外部 CDN・vendored ライブラリはありません。
- WebGL が使えない環境でも、Canvas 2D が使えれば表示できます。
  Canvas 2D すら取得できない場合は、検索できる HTML 一覧へフォールバックします
  （`#r3d-fallback`）。

### 3D 配置（`layout3d.js`）

旧版は 2D の XZ をそのまま使い、Y を分野段とハッシュだけで決めていたため
（実測 X:Y:Z ≈ 129:30:74）、薄い板のように密集していました。現在は次の決定的な
3 段階で、Y・Z にも実体積を持たせます。

1. **分野ごとの局所平面の回転・傾斜**: 各分野の 2D 局所座標を、分野ごとに決まった
   角度（回転 ±3.0 rad 上限、傾き ±0.62 rad 上限）の正規直交基底へ剛体変換します。
   分野内の相対配置は距離を保ったまま 3D に傾くため、局所的な関連は壊れません。
   分野アンカーは 2D 重心の X/Z と分野段の Y に置きます。
2. **決定的な緩和**: 反応ペアのばね（自然長 6.5）、近距離反発（半径 7）、
   分野アンカーへの弱い引力を 110 反復。乱数は使わず、順序も固定です。
   近距離反発で密集をほどき、ばねで反応のつながりを近くに保ちます。
3. **分野段の再整列と最小間隔**: 各分野の平均 Y を分野番号の段へ平行移動で揃え、
   残った極端な近接（4.2 未満）だけを決定的に押し離します。最後にもう一度段を揃えます。

実測（Node、427 物質、通常反応 162）:

| 指標 | 旧 | 現 |
|---|---:|---:|
| 範囲 X:Y:Z | 129 : 30 : 74 | 98 : 78 : 58 |
| 最近傍距離の中央値 | 1.59 | 6.35 |
| 反応ペア距離の中央値 / 平均 | 6.91 / 9.67 | 8.82 / 9.38 |
| 投影カードの重なり組（既定 / 回転2視点） | 22,629 / 29,376 / 17,748 | 5,213 / 6,290 / 6,386 |

- 乱数なし。同じ入力からは常に同じ座標。構築は Node で約 250ms（ブラウザ実機は未計測）。
- **2D 用の学術配置（`x / y`）は読みません。** 3D が読むのは座標なしの
  `academic-facts.js` だけで、ばねに使うのは通常データの `reactions` です。
  2D 側のレイアウトが再生成されても 3D 座標は変わりません。
- 分野の高低差は平均 Y が分野番号順になることをテストで確認しています。分野内の
  形は剛体変換で保ちますが、全体の 2D 地図としての見た目は回転・傾斜で変わります。

### 正面カードと不透明オクルージョン（`projection.js` / `renderer.js`）

- 3D の点を透視投影し、その画面座標を中心に **画面軸平行の矩形**を描きます。
  3D でカードを傾けないため、真横から見ても線に潰れず、鏡像にもなりません。
- **重なりを理由にカードを間引しません。** カード枚数の上限もありません。
  投影された物質はすべてカード（検索・未接続の絞り込み時は点）として計画に入り、
  奥（投影 z 大）から手前（z 小）へ不透明で描きます。手前のカードが実際に重なった
  範囲だけを上書きするので、見た目は「重なった紙を重ねた」状態になります。
- 当たり判定は描画順の逆（手前から）で、その点を実際に覆っているカード／点のうち
  最も手前のものを返します。選択カードだけは最後（最前面）に描き、文字を常に読める
  ようにします（優先配置。他のカードを消すのではなく上に載せる）。
- 詳細パネル・ヘッダ・ツールバーの矩形は「隠れる領域」として扱い、その中心にある
  カード／点は計画から外します（パネルの裏は見えないため）。重なり以外の理由で
  データを消すことはしません。
- 奥行きは点の大きさ・エッジの濃さ・カードの塗り色（不透明のまま暗く）で表します。
  文字サイズは可読最小 12px を下回りません。既定カメラはやや見下ろす角度で、
  床にはワールド平面の薄いグリッドを投影して奥行きの手掛かりにします。
- 通常経路（非選択）の線は、選択がないときも追える濃さを確保します。奥行きで
  薄くしても下限を設け、大学層の破線も同様です。選択経路はより明るく・太く・発光し、
  明確に区別できます（詳細パネルで条件も確認できます）。
- 選択物質の正規構造式（共有 `site/shared/organic-structure.js` の SVG）だけを、
  その物質のワールド位置に結び付いた少し傾いた平面として 3D 内に置きます。
  結合の 3D 座標は発明せず、SVG を 1 枚の画像として貼るだけです。ラスタ化に
  失敗した場合は示性式の文字面、それも無ければ詳細パネル側の表示に任せます。

### ホイールズーム（カーソル固定）

- ホイールは画面中央固定ではなく、**カーソル下の点を固定**して拡大・縮小します。
  カーソル下にカードがあればその物質の world 座標、なければ視線上のターゲット平面の
  点をアンカーにします。
- 距離を変えた後、アンカーが同じ画面座標へ来るよう `camera.target` を
  right/up 平面で平行移動します（回転なし・追加ズームなし・選択変更なし）。
- ズーム上限/下限に当たってもアンカーの画面位置は動きません。同じカーソルでの
  連続ホイールでもドリフトしません（数値テストで 1e-6 以内）。
- ズームボタン・キーボードの `+` / `-` は従来どおり中央基準、ピンチは中点基準です。

### 静的な描画と性能（`renderer.js`）

- `requestAnimationFrame` は入力・選択・リサイズ時に **1 回だけ** 予約するコアレス方式。
  アイドル時のループ・`setInterval`・自動回転はありません。
- 透視投影のカメラ基底は 1 フレームに 1 回だけ計算して全点で使い回します。
- エッジは **スタイル（選択 / 通常 / 大学破線 / 減光）× 奥行き 3 バンド** でまとめ、
  1 バッチ 1 回の `stroke` にします。1 本ごとの `save/restore` や破線設定はしません。
  選択矢印だけは本数が少ないので個別に描きます。
- 画面外のエッジは Liang–Barsky で切り詰め、完全に外れたものは描きません。
  描画前後の本数を `plan.stats`（`edges` / `culledEdges` / `edgeBatches`）に残します。
- 背景の放射グラデーションはサイズごとにキャッシュ。カードの塗り色・文字幅・
  床グリッド・構造式の面は計画時に一度だけ計算します。
- 実機の FPS は測っていません（この試作は自動テストのみ）。427 枚のカードを
  間引かない方針のため、低性能端末では負荷が高くなる可能性があります。

### 層とグループ

- 公開版は常に「通常＋大学」の合成（308 グループ = 通常 156 + 大学レベル 152）。
  層の切替はありません。
- 色の対応: **通常経路 = アンバー `#ffd166`**、**大学レベル専用 = シアン `#48e4ff`**。
  3D のハイライト線・矢印と、詳細の反応カード左アクセント・大学バッジで同じ値を使います。
  通常＋大学の共通（mixed）グループは、アンバー地にシアンの内側アクセントと
  「共通グループ」バッジで二重に示します（現在の実データには mixed はありません）。
- グループ内の条件・試薬・係数・出典は member に保持し、表示パネルで条件を出します。
- 経路グループの折りたたみ `summary` にも、**基質（複数可） → 生成物（複数可）の全端点名**を
  表示します（選択中の物質も含む）。生成物 ID のない経路は `productNote` を生成物側に使い、
  長い名前は省略記号・横スクロールにせず折り返します。反応式 SVG は開くまで生成しません。
- 逆向きの反応は `groupKey` の仕様どおり別グループ。3D 側で勝手に統合・反転しません。

### 幾何として検証したこと / 主観的なもの

数値テストで検証済み:

- 3D 範囲の X:Y:Z 比、最近傍距離の中央値、反応ペアの距離、分野平均 Y の昇順、
  同一分野ペアが分野間ペアより近いこと。
- 既定・回転 2 視点での投影カード重なり組数の上限。
- ホイールズームで、複数のカーソル位置・カメラ向き・拡大/縮小・クランプ後・
  連続操作でもアンカーの投影座標が一致すること。

主観的・未検証:

- 「密集が減って見やすい」「線が読みやすい」という体感は実ブラウザで未評価です。
- 実際の描画負荷（FPS）は端末で測っていません。配置構築は Node で約 250ms です。

## 限界・未確認

- 実ブラウザでの見た目・操作感・スクリーンショット確認は、このサブエージェントでは
  行っていません（親セッション側で確認する前提）。自動テストは幾何・データ・計画までです。
- 3D は「既存 2D 配置 + 決定的な高さ」であり、力学シミュレーションではありません。
  分野の段差と ID ハッシュで奥行きを作るため、物質間の 3D 距離は化学的距離ではありません。
- OCR 的な画像比較や WebGL の有無は判定していません。Canvas 2D 前提です。
- **実機の性能は測っていません。** 427 枚のカードを重なりで間引かない方針のため、
  低性能端末・大きな画面では描画負荷が高くなる可能性があります。エッジの本数・
  バッチ数・画面外の除外数は `plan.stats` で確認できますが、FPS は未計測です。
- 不透明カードの重なりは「手前が勝つ」描画ですが、カードが密集すると名前が
  重なって読めない箇所が残ります（間引かない方針の代償）。選択カードだけは最前面です。
- 大学レベル層の内容（反応の追加・修正）は元データ（`site/app11/academic-data.js`）の更新に追従します。
  3D は事実データ（`academic-facts.js`）を再生成して読み、レイアウト再生成の影響は受けません。
- 構造式は共有レンダラの SVG をそのまま表示します。巨大な構造はパネル内で縮小されます。
- モバイルの実機タッチは未確認です。ピンチ・中点移動・1 本指モードの計算ロジックは
  単体テスト済みですが、端末固有のジェスチャとは異なる場合があります。2 本指のひねりは
  誤操作防止のため意図的に回転へ割り当てていません（回転は 1 本指「回転」か Shift+矢印）。
- 公開は Pages のステージング生成（`scripts/app11/build-pages-staging.cjs`）で行います。
  実際のデプロイは親セッションが担当します（この作業では commit / push / deploy をしていません）。
