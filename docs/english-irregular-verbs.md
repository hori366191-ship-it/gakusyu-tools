# 中学校英語 不規則動詞一覧（独自作成）

## 1. この資料について

中学校英語で扱う不規則動詞の変化を、学習用に整理した独自作成の一覧です。

- **位置づけ**: 公式の一覧でも、特定の検定教科書が示す単語リストの転載でもありません。学習指導要領が示す文法範囲（過去形・過去分詞・現在完了など）と、一般に公開されている不規則動詞の情報を参照し、本資料用に取捨選択・配列・記載を行ったものです。
- **範囲**: 中学校で学ぶ基本的な動詞を中心に、発展的な語を加えています。高校以降の細かな語や古風な形は扱いません。
- **作成方針**:
  - 見出し語の選定・並び順（アルファベット順）は本資料独自のものです。
  - 変化形（原形・過去形・過去分詞）は言語上の事実として記載しています。
  - 意味は、教科書の語義説明を写したものではなく、一般的な語義を簡潔に自作したものです。
  - 例文・本文・イラストは掲載していません（単語の変化形の確認に用途を限定）。

## 2. 表記ルール

- 列は **原形 | 過去形 | 過去分詞 | 意味 | 型** の5列です。
- 原形が三人称単数で形を変えるものは、括弧内に示します（例: `be (am/is/are)`、`do (does)`）。
- **型** は原形・過去形・過去分詞の変化パターンを示します。
  - `A-A-A`: 3形が同じ（例: cut - cut - cut）
  - `A-B-A`: 原形と過去分詞が同じ（例: come - came - come）
  - `A-B-B`: 過去形と過去分詞が同じ（例: make - made - made）
  - `A-B-C`: 3形がすべて異なる（例: go - went - gone）
  - `A-A-B`: 原形と過去形が同じ（例: beat - beat - beaten）
  - `その他`: 上の型に当てはまらないもの（be など）
- 英米で形が分かれる場合は「/」で併記します（例: `got / gotten`）。その場合の型も「/」で併記します。
- 意味が複数に分かれる語は、代表的な語義を「／」で示します。

## 5. 注意事項

- **read** はつづりが3形同じですが、発音が変わります（/riːd/ → /red/ → /red/）。型は A-A-A ですが「音は同じではない」点に注意してください。
- **get** の過去分詞はイギリス英語で `got`、アメリカ英語で `gotten` が一般的です。型も A-B-B / A-B-C の両方が考えられます。
- **learn / dream / light / burn / smell / spell** は `-ed` 形と `-t` 形の両方が使われます。地域差・用法差があり、どちらも誤りではありません。
- **hang** は「物を掛ける」が `hung`、「絞首刑にする」が規則変化の `hanged` です。意味によって形が変わります。
- **shine** は「輝く」（自動詞）が `shone`、「～を磨いて光らせる」（他動詞）が `shined` と使い分けることがあります。
- **lie / lay** は特に混同しやすい語です。
  - `lie`（横になる）: lie - lay - lain（不規則）
  - `lay`（～を横たえる）: lay - laid - laid（不規則変化・A-B-B）
  - `lie`（嘘をつく）: lie - lied - lied（規則変化。上の `lie` とは別の語）
- **show** の過去分詞は `shown` が一般的ですが、`showed` も使われます。
- **wake** は `woke - woken` が一般的で、`waked` はまれです。
- **be / do / have** は主語や時制によって形が細かく変わる特殊な動詞です（be は am/is/are、do は does、have は has）。表中では代表形のみを示しています。

## 6. 型のまとめ

| 型 | 変化の特徴 | 代表例 |
|---|---|---|
| A-A-A | 3形がすべて同じ | cut - cut - cut / put - put - put / read - read - read |
| A-B-A | 原形と過去分詞が同じ | come - came - come / become - became - become / run - ran - run |
| A-B-B | 過去形と過去分詞が同じ | make - made - made / buy - bought - bought / teach - taught - taught |
| A-B-C | 3形がすべて異なる | go - went - gone / see - saw - seen / write - wrote - written |
| A-A-B | 原形と過去形が同じ | beat - beat - beaten |
| その他 | 上の型に当てはまらない | be - was, were - been |

- 意味は本資料用に自作した簡潔な語義です。
