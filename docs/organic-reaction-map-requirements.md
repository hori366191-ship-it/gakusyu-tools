# 有機化学 反応経路マップ — 要件定義（計画のみ）

- 版: 2026-11-10（第2版: 未承認の設計決定を候補へ戻し、状態区分と安全記述を修正）
- 状態: **計画・要件のみ（実装なし）**
- 対象: 本ドキュメント1ファイルのみ。コード・既存アプリ・ポータル・テーマには触れない
- 引き継ぎ先: 別セッション（新規実装担当）。本書は「満たすべきこと」を定義し、方式の詳細は §3・§5 で決める

## 0. 本書の位置づけ

- 有機化学の反応経路を **1枚の地図** として俯瞰し、必要な箇所だけ詳細化する学習ツールの要件を定める。
- **実装・新画面のリンク追加・デプロイは行わない**。現公開アプリの改修（並行作業中）とは独立で、その完了を待たない。
- 参照した外部資料の **サイト名・URL・具体的な図の配置・独自の表記記号（† など）は本書に書かない／引き継がない**。第三者の系統図・PDF・画像の切り出し・トレース・配置説明も引き継がない。分類・配置は本ツール独自に設計する（§4）。これは既知資料からの影響を減らすための方針であり、法的安全性を保証するものではない。

## 1. 目的 / 非目的

### 目的（優先順）

1. **体系の俯瞰**: 有機化学全体のつながりを1画面で把握できる。
2. **必要時の詳細**: 気になった物質・反応だけを、その場で深掘りできる。
3. 位置関係が安定していて、同じ物質を毎回同じ場所で見つけられる。
4. 分野の枠をまたぐつながり（例: 官能基変換と高分子・生体分子）が見える。

### 非目的

- 網羅的な暗記カード集、問題集、採点機能
- 実験書・調製マニュアル（§2.11）
- 収録外の化合物・反応の自動生成や推測補完

## 2. 決定要件（Must）

### 2.1 一枚の地図 / 俯瞰と拡大

- 全収録物質・反応を **単一のキャンバス** に配置する。画面遷移で分断しない。
- ズームとパンで、全体から詳細まで見られる。

### 2.2 位置関係の安定

- 同じ物質・反応は、**ズーム・パン・リロード・テーマ切替・端末幅の変更の前後で同じ位置関係** に置かれる。
- データ更新時も、既存ノードの位置が不必要に動かない。
- 保持の方式（固定座標／制約付き自動配置など）は §3 で決める。本要件は方式を指定しない。

### 2.3 分野横断の接続

- エッジは「同一分類内」と「分野横断」を区別して描き分ける（色はテーマ変数）。
- 横断エッジは俯瞰時に埋もれないようにする（長距離リンク等の表現は §3）。
- 分類の数・名称は固定しない（§4）。

### 2.4 Semantic zoom（最初の視覚負荷を抑える）

- 同じ図の単純拡大ではなく、**詳細度の段階に応じて表示要素を切り替える**。位置は動かさない。
- 初期表示は全体を俯瞰し、ラベル・注記を間引く。拡大に応じて物質名・反応種別・条件が現れる。
- 同じズーム状態では常に同じ内容を表示する（ランダムな間引き・ちらつきをしない）。
- 段階数・境界の決め方は §3。

### 2.5 全体へ戻る / 現在位置

- **1操作で全体表示に戻れる**（マウス・タッチ・キーボードで到達可能）。
- 現在位置（どの分類・物質・反応を見ているか）を常時表示する。
- 現在位置の URL 反映・復元は §3 の候補（必須要件にしない）。

### 2.6 詳細は同一ページのフローティングカード

- 物質・反応のタップ／クリックで、**同じページ内** にカードを開く。ページ遷移・別タブを開かない。
- 閉じる操作: **カード外のクリック／タップ** と **Escape キー**。
- 開いたときはカード内へフォーカスを移し、**閉じたら元のノードへフォーカスを戻す**。
- キーボードだけで「ノードへ移動 → 開く → カード内を読む／操作する → 閉じる」が完了できる。
- モーダルにするか非モーダルにするか、モバイルでの提示形式は §3。

### 2.7 物質カード → 既存ビルダーへの遷移

- 物質カードに「ビルダーで開く」導線を置く。遷移先は既存の有機化学ビルダー（`site/app10/`）の **focus クエリ**。
- URL 形式は既存 `routeHref()` の生成規則（`mode` / `family` / `cpartial` / `shape` / `system` / `preset` / `category` + 末尾 `focus=<compoundId>`）に一致させる。`focus` を必須とする。
- ビルダーの収録IDと地図の物質IDの対応をデータ側で保持し、**存在しないIDへのリンクを生成しない**（対応が取れない物質はリンクを出さず「ビルダー収録外」と表示）。
- 地図はビルダーの内部実装を実行時に読み込まない（独立性）。整合はオフライン検査で担保する。

### 2.8 反応詳細 = 共通説明 + 個別情報

反応カードは次の2層を **視覚的・意味的に分離** して表示する。

1. **共通の反応説明**: 反応種別（付加・置換・脱離・縮合・加水分解・酸化還元・重合 など）として「何がどう変わるか」の一般則。模式図を添えてよい。
2. **個別情報**: その反応の基質（複数可）、生成物（主生成物／副生成物）、試薬・条件、例外・注意（位置選択性など）。

- 共通説明は反応種別ごとに整理し、同じ説明を個別反応ごとに重複記載しない（保持・再利用の方法は実装時）。

### 2.9 双方向の追跡

- 物質カードに **「この物質の製法（入ってくる反応）」** と **「この物質からの生成物（出ていく反応）」** の両方を表示する。件数が分かるようにする。
- 0件のときは理由を区別して表示する（§2.10）。
- 原料から辿る専用モードの要否は §3。

### 2.10 状態の区別（未確認を「不可能」と表示しない）

| 状態 | 意味 | 表示 |
|---|---|---|
| 確認済 | 独立資料で確認できた | 通常表示 |
| 未確認 | 対象だが未検証・情報不足・判断不能 | 「未確認」中立表示。断定・不可能扱いをしない |
| 収録外（対象外） | このツールの収録範囲に含めていない | 「収録外」 |
| 不可能 | **明確な根拠** により成立しないと確認できた | 理由付きで「該当しない」 |

- 判断できない場合は必ず **未確認** に置く。未確認を不可能・収録外として表示しない。
- 「原料から到達できない」は「経路未確認」であり、不可能ではない。
- 化学的に誤解を招く断定（例: データがないことを「生成しない」と書く）をしない。

### 2.11 事実検証・模式図と機構・安全

- 収録する反応・生成物・試薬・条件は **独立した資料で確認** する。未確認のものを確認済みとして書かない（推測で埋めない）。
- 公開する事実には検証記録（資料の識別情報・該当箇所・確認日）を付ける。記録のないものの扱い（注記表示／公開除外）は §3。
- **学習上必要な条件は記載してよい**: 触媒、温度、圧力、溶媒など、高校化学の理解に必要な反応条件は検証のうえ記載する（条件を落として一般論だけにしない）。
- **実験書・調製マニュアルにしない**: 実施を促す試薬量・濃度・具体的な操作手順・装置の使い方は扱わない。危険性の一般的注意（換気・保護具など）に留める。
- **模式図と機構を区別** する。模式図＝原子団・結合の変化を示す図、機構＝電子の動きを示す図。UI上でラベルを分け、混在させない。機構図を収録するかは未決（§5）。
- 出典の扱いは既存のクレジット方針に合わせ、公開面には資料名等の最小限のみを出し、本文抜粋・画像の直リンクは配信しない。

### 2.12 既存規約に従う（テーマ / reduced motion / モバイル）

- **3テーマ**: `site/themes/theme.js` の `data-theme`（標準 / ポップ / フォレスト）に追従。地図の色・線種は CSS 変数化し、3テーマで成立させる。テーマ切替UIは新設しない。
- **reduced motion**: 既存アプリの慣例（`@media (prefers-reduced-motion: reduce)` と JS の `matchMedia` 判定）に従い、アニメーションと慣性を無効化できる。
- **mobile pan / zoom**: ズーム・パンができ、**ページスクロールを奪わない**。ブレークポイントは既存アプリの 760px / 430px に合わせる。実装方式（自前／ライブラリ）は §3。
- 390px 幅で横スクロールを出さない。

### 2.13 独立性・作業境界

- 本書の作業範囲は本ファイルのみ。`site/`・`design-lab/`・`site-gas/`・`site-worker/`・`scripts/` は変更しない。
- 実装は別セッション・別作業。実装先とポータルへのカード追加は、既存アプリの並行作業が完了してから別途判断する。
- 既存アプリのデータ（自由文の反応メモ等）を地図のデータ源として流用しない。

## 6. 次セッションの検討順

1. **スコープ確定**: 対象読者、収録範囲、初期ビュー（§5 #1）。
2. **分類体系の設計**: §4 の方針からカテゴリ・階層・横断の定義を作る（§5 #2）。
3. **反応の語彙とデータ表現**: 反応種別の語彙、状態区分、検証記録の書式、ID 規則（§5 #3）。
4. **検証パイロット**: 10〜20 反応を独立資料で確認し、検証フローと未確認・保留の扱いを確立（§2.11）。
5. **位置安定の方式検討**: §3 #3 の候補を比較し、更新時の安定性の検証方法を決める。
6. **ワイヤーフレーム**: semantic zoom、カード（外タップ・Escape・フォーカス復帰）、全体へ戻る／現在位置。
7. **非機能の方針確定**: テーマ、reduced motion、モバイル pan/zoom、代替表示（§2.12・§3）。
8. **受入条件のテスト化**: 位置安定・状態区分・リンク整合・文言をオフラインで検査できる形にする。
9. **試作 → 本流移植の判断**（§5 #8）。ポータル追加は最後。

## 7. 受入条件

- [ ] 同一データ版で、ズーム・パン・リロード・テーマ切替・端末幅変更の前後にノードの相対位置が変わらない。
- [ ] 初期表示はラベルが間引かれ、拡大に応じて物質名・反応・詳細が現れる（段階数は問わない）。
- [ ] 同じズーム状態で同じ内容が表示される（ちらつき・ランダム間引きがない）。
- [ ] 全体表示へ1操作で戻れ、現在位置の表示が実際のビューと一致する。
- [ ] 物質・反応のタップ／クリックで同ページにカードが開き、ページ遷移しない。
- [ ] カード外クリック／タップと Escape で閉じ、フォーカスが起点ノードへ戻る。
- [ ] キーボードのみで、ノード選択 → カード内操作 → 閉じる、まで完了できる。
- [ ] 物質カードのビルダーリンクが `focus=<id>` を含み、対応の取れない物質ではリンクが出ない（存在しないIDへのリンクがない）。
- [ ] 反応カードで「共通説明」と「個別（基質・生成物・試薬条件・例外）」が分離して表示される。
- [ ] 各物質で「製法」と「生成先」の両方が表示され、0件時に「未確認」「収録外」「不可能」が区別される。
- [ ] 未確認・収録外の物質／反応を「不可能」「生成しない」と表示していない。
- [ ] 公開する事実に検証記録があり、確認済みと未確認が表示上区別される。
- [ ] 学習上必要な触媒・温度等の条件が記載され、かつ試薬量・具体操作手順・装置手順が本文に含まれない。
- [ ] 模式図と機構図がラベルで区別され、混在しない。
- [ ] 3テーマすべてで地図の線・ラベル・コントラストが破綻しない。
- [ ] reduced motion 有効時、アニメーションと慣性が無効になる。
- [ ] 390px 幅で横スクロールが出ず、地図領域外のページスクロールが維持される。
- [ ] 文書・データ・コードに、参照元のサイト名・URL・具体的な図配置・独自表記記号（† 等）が引き継がれていない（レビュー項目）。
- [ ] `site/`・`design-lab/`・ポータル・テーマに差分がない（独立性）。
