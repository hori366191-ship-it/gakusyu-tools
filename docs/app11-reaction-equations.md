# app11 反応カードの反応式（equation）

反応カードの「この反応の個別情報」に、構造式で反応物 → 生成物を示す図を出す。
係数・副生成物・矢印の上下の条件（触媒・温度）まで含められるが、**収支を偽らない**ことを
最優先にし、式の確からしさに応じて4つの表示modeを使い分ける。

- 正本: `site-src/app11/reactions.json` の各反応の `equation`
- 無機・イオンの構造: `site-src/app11/species.json`（反応式専用。427物質には加えない）
- 公開データ: `site/app11/data.js` の `reactions[].equation` と `species`
- 描画: `site/shared/organic-structure.js` の `renderEquation`（`site/app11/structure-draw.js` が再エクスポート。一般図16変換と共通）
- 検証: `node --test scripts/tests/app11-reaction-equations.test.cjs`

## mode

| mode | 意味 | 表示の見出し | 収支の検査 |
|---|---|---|---|
| `B` | 完全な反応式（係数・副生成物まで） | 反応式（構造式） | 元素＋電荷を必須 |
| `N` | 正味の総括式（塩の生成・中和・後処理を省略） | 正味の反応式（総括） | 元素＋電荷を必須 |
| `T` | 構造変換図（試薬由来の生成物・プロトン源・保護基を省略） | 構造変換図 | 主張しない |
| `P` | 重合反応の模式式（繰り返し単位 n・末端省略） | 重合反応の模式式 | 主張しない |

`T`・`P` は「完全な反応式ではない」と図の下に明記する。`B`・`N` は元素収支と電荷収支が
合わなければ `build-map-data.cjs` が停止する（fail-closed）。未知の元素記号、未収録の物質ID、
未定義の無機species、1〜9以外の係数も同じく停止する。

## schema

```json
"equation": {
  "mode": "B",
  "arrow": "to",              // to | equilibrium
  "above": "強酸触媒",         // 矢印の上（触媒・試薬）
  "below": "",                // 矢印の下（温度・その他の条件）
  "title": "",                // 任意。T/P の見出しを上書きする
  "explanation": "",          // 任意。図の下に出す補足（120文字まで）
  "left":  [ { "compound": "acetic-acid" }, { "compound": "ethanol" } ],
  "right": [ { "compound": "ethyl-acetate" }, { "species": "H2O" } ],
  "variants": [               // 任意。T だけで使う代替経路（平衡）
    { "label": "グルコースへの異性化", "arrow": "equilibrium", "left": [ ... ], "right": [ ... ] }
  ],
  "verification": [ { "source": "OpenStax Organic Chemistry (McMurry)", "section": "21.6", "title": "...", "url": "...", "date": "2026-11-16" } ]
}
```

- 各項目は `compound` / `species` / `text` のどれか1つだけを持つ。`coef` は 1〜9 の整数、
  `P` だけ `"n"` / `"2n"` を許す（省略時は1）。
- `text` は `T` 専用。構造を定義できない生成物（タンパク質の加水分解生成物「アミノ酸類」など）を、
  存在しない物質IDを作らずに示すための表示用テキスト。
- `verification` は式の根拠。既存の `reactions[].verification` は変更せず、そのまま残す。
  式の資料は図の下にだけ出し、反応の検証記録（`sources`）には混ぜない。

## 係数と根拠の扱い

- 係数は元素収支（と電荷収支）から決めたもので、**個別の実験を再検証したという主張ではない**。
- 条件の文言は既存 `conditions` を保持したまま、`above` / `below` に対応する語を置く。
  存在しない触媒・温度・試薬は追加しない。`above` と `below` は同じ文言を繰り返さない。
- 既存 `note` / `productNote` / `conditions` は公開データでも変更しない（テストで固定）。

## 表示の規則

- 反応式は「この反応の個別情報」の見出し直後、既存の `dl`（基質・試薬・生成物・条件・例外・注意・分野）の前に置く。
- 係数は構造の左、`＋` は構造の間、矢印は左右の間。`above` / `below` は矢印の列の上下に置く。
- カード内では反応式を横スクロールさせない。1段に収まる短い式は図全体をカード幅へ縮小し、
  1段の自然幅が **600px を超える式**は、反応物（上段）・縦矢印と条件（中央）・生成物（下段）の
  2段に積む。段組みでは矢印を縦向きにし、条件は矢印の横へ重ねずに置く。係数・`＋`・物質の順序は
  1段のときと同じ。
- 反応カードでは行の高さを 200px、1構造の最大幅を 300px、縮小率の下限を 0.55 にして描く
  （`REACTION_EQUATION_OPTS`、段組みは `stack: true` を足す）。具体物質は一般図の骨格より
  背が高いため、高さで潰さず行を広げる。一般図の既定（120px・250px・1段）は従来のまま。
- カードの式はボタン（`data-eq-open`）で、tap / Enter / Space により大きめの native `dialog`
  で開く。ダイアログはカード内で選んだ SVG をそのまま複製するため、2段の式は拡大しても2段のまま
  （再描画して1段に戻さない）。dialog は式の自然幅で表示し、狭い画面では本文を横スクロールする。
  カード・選択は残し、閉じるボタン / Esc で起点の式ボタンへフォーカスを戻す。モーダル中の
  背景クリックでカードは閉じず、地図のズーム・パン・キー操作も届かない。一般図16変換の式も
  同じ操作で拡大できる。
- 段組みの閾値（600px）は実際の収録式の自然幅（反応 501〜1762px、一般図 683〜1103px）から決めた。
  600px 以下の6式程度は1段のまま。**目視・スクリーンショットでの確認は未実施**で、判断は
  `scripts/tests/app11-equation-dialog.test.cjs` の描画・幅・DOM 配線テストによる。
- 示性式しか無い物質は「示性式・名称で表示している項目があります（構造式ではありません）」と明記する。
  構造specが無い項目は文字の箱で描き、構造式と偽らない。
- `variants` は1経路につき1図（同じ見出しに経路名を付ける）。各図が独立した拡大ボタンを持つ。

## 一般図（classMap）との関係

一般図16変換の `equation` は `arrow` / `left` / `right` だけを持ち、`above` / `below` を足さない。
描画は `renderEquation` を共有し、**オプション無しの既定出力**は従来と同一（テストで固定）。
カード内の一般図16式も、自然幅が600pxを超えるため2段＋拡大ダイアログの対象になる。
反応カード用に式を足しても、具体図の投影（物質・反応・分野・型・状態）と一般図の座標は変えない。
`scripts/tests/app11-hit-targets.test.cjs` は具体図のハッシュから `equation` を外し、
式だけのハッシュ（`EQUATION_SHA256`）を別に固定している。

## 既知の限界

- 重合（`P`）は末端を省略した模式式で、水は `2n` 分子として示す（有限鎖の `2n-1` は使わない）。
- `N` は NaOH 処理→酸性化などの後処理をまとめた総括式で、塩の種類・中和量は示さない。
  （加水分解で生じるのは遊離酸で、酸化ではない）
- `T` は係数を主張しない。酸化・還元・ペプチド結合・糖の異性化など、試薬由来の副生成物や
  保護基の脱着を省略している。
- フルクトースの塩基性異性化は1分子から2分子が生じないため、グルコース経路とマンノース経路の
  2つの平衡（`variants`）として示す。
- ブラウザでの目視確認は本変更では行っていない（自動テストのみ）。
