# 中学数学

## 数と式

### 正負の数
- **絶対値**: 数直線上の原点からの距離を表します。$|3| = 3$、$|-3| = 3$
- **加法・減法**: 同符号は絶対値の和に同じ符号をつける。異符号は絶対値の差に、絶対値の大きい方の符号をつける。
- **乗法・除法**: 同符号の積・商は正、異符号の積・商は負。
- **累乗**
    - $a^n$ は $a$ を $n$ 回かけた値です。例: $(-2)^2 = 4$、$-2^2 = -4$
- **分配法則**
    - $a(b+c) = ab+ac$
- **素因数分解**: 自然数を素数の積で表します。例: $12 = 2^2 \times 3$

### 文字式
- **表し方の約束**
    - 積は、数は文字の前、文字はアルファベット順に書きます。
    - 同じ文字の積は累乗で表します（$a \times a \times a = a^3$）。
    - 商は分数で表します。
    - $1$ と $-1$ は省略します（$1x \rightarrow x$）。
- **式の値**: 文字に数を代入して計算した値です。
- **項と係数**: 式を加法だけの形にしたときの1つ1つを項、文字を含む項の数の部分を係数といいます。

### 一次方程式
- **等式の性質**: 両辺に同じ数を足す・引く・かける・割っても、等式は成り立ちます。
- **移項**: 項を符号を変えて反対の辺に移すことを移項といいます。
- **比例式**
    - $\frac{a}{b} = \frac{c}{d}$ のとき $ad = bc$（外項の積 = 内項の積）
    - 例: $x : 3 = 4 : 6$ のとき $6x = 12$ より $x = 2$

### 連立方程式
- **加減法**: 係数をそろえて2つの式を足したり引いたりして、1つの文字を消去します。
- **代入法**: 一方の式を他方の式に代入して、1つの文字を消去します。

### 速さと割合
- **速さ・距離・時間**
    - 速さ = 距離 ÷ 時間
    - 距離 = 速さ × 時間
    - 時間 = 距離 ÷ 速さ
- **割合**
    - 割合 = 比べる量 ÷ もとにする量
    - 比べる量 = もとにする量 × 割合
    - もとにする量 = 比べる量 ÷ 割合
    - 百分率は割合を $100$ 倍したもの（例: 20% は $0.2$）

### 乗法公式（展開）
- $(a+b)^2 = a^2 + 2ab + b^2$
- $(a-b)^2 = a^2 - 2ab + b^2$
- $(a+b)(a-b) = a^2 - b^2$
- $(x+a)(x+b) = x^2 + (a+b)x + ab$

### 因数分解
- $a^2 + 2ab + b^2 = (a+b)^2$
- $a^2 - 2ab + b^2 = (a-b)^2$
- $a^2 - b^2 = (a+b)(a-b)$
- $x^2 + (a+b)x + ab = (x+a)(x+b)$
- **共通因数でくくる**
    - $ab + ac = a(b+c)$

### 平方根
- $\sqrt{a} \times \sqrt{b} = \sqrt{ab}$
- $\frac{\sqrt{a}}{\sqrt{b}} = \sqrt{\frac{a}{b}}$
- **分母の有理化**
    - $\frac{k}{\sqrt{a}} = \frac{k\sqrt{a}}{a}$
- **大小比較**: 正の数 $a, b$ について、$a < b$ なら $\sqrt{a} < \sqrt{b}$ です。
- $\sqrt{a^2} = |a|$

### 二次方程式
- **解の公式**: $ax^2 + bx + c = 0$ の解は
    - $x = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$
- **因数分解による解法**: $(x-p)(x-q) = 0$ の解は $x = p, q$ です。
- **平方根による解法**: $x^2 = k$ の解は $x = \pm\sqrt{k}$ です。

## 図形

### 平面図形
- **おうぎ形の弧の長さ**
    - $l = 2\pi r \times \frac{a}{360}$（$r$は半径、$a$は中心角）
- **おうぎ形の面積**
    - $S = \pi r^2 \times \frac{a}{360}$（$r$は半径、$a$は中心角）
    - 弧の長さ $l$ を使うと $S = \frac{1}{2}lr$
- **円錐の側面積**
    - $S = \pi r l$（$r$は底面の半径、$l$は母線の長さ）
- **円錐の側面のおうぎ形の中心角**
    - $360^\circ \times \frac{r}{l}$（$r$は底面の半径、$l$は母線の長さ）
- **図形の移動**: 対称移動・平行移動・回転移動があります。移動しても形と大きさは変わりません。

### 角度
- **n角形の内角の和**
    - $180^\circ \times (n-2)$
- **n角形の外角の和**
    - $360^\circ$
- **正多角形の1つの内角**
    - $\frac{180^\circ \times (n-2)}{n}$
- **正多角形の1つの外角**
    - $\frac{360^\circ}{n}$
- **対頂角**: 2直線が交わるとき、向かい合う角は等しい。
- **平行線の性質**: 同位角は等しい、錯角は等しい。
- **三角形の内角の和**: $180^\circ$ です。1つの外角は、となり合わない2つの内角の和に等しい。

### 三角形の性質
- **二等辺三角形**
    - 2つの底角は等しい。
    - 頂角の二等分線は、底辺を垂直に2等分する。
- **正三角形**: 3つの辺が等しく、3つの角はすべて $60^\circ$ です。
- **直角三角形の合同条件**: 斜辺と他の1辺がそれぞれ等しい。斜辺と1つの鋭角がそれぞれ等しい。
- **角の二等分線と辺の比**
    - $\triangle ABC$ の $\angle A$ の二等分線が辺BCと交わる点Dについて、$BD : DC = AB : AC$
- **ヘロンの公式 <span class="tag-maniac">マニアック</span>**
    - 3辺の長さが $a, b, c$ の三角形の面積は $S=\sqrt{s(s-a)(s-b)(s-c)}$（$s=\frac{a+b+c}{2}$）

### 三角形の合同条件
- 3組の辺がそれぞれ等しい。
- 2組の辺とその間の角がそれぞれ等しい。
- 1組の辺とその両端の角がそれぞれ等しい。

### 四角形
- **平行四辺形の性質**
    - 2組の対辺はそれぞれ平行で、長さが等しい。
    - 2組の対角はそれぞれ等しい。
    - 対角線はそれぞれの中点で交わる。
- **平行四辺形になる条件**: 2組の対辺が平行・2組の対辺が等しい・2組の対角が等しい・対角線がそれぞれの中点で交わる・1組の対辺が平行で長さが等しい、のどれかが成り立てばよい。
- **特別な平行四辺形**
    - 長方形: 4つの角がすべて $90^\circ$ の平行四辺形。対角線の長さは等しい。
    - ひし形: 4つの辺が等しい平行四辺形。対角線は垂直に交わり、それぞれの角を2等分する。
    - 正方形: 長方形でもありひし形でもある平行四辺形。対角線の長さは等しく、垂直に交わり、それぞれの角を2等分する。
    - 1辺 $a$ の正方形の対角線の長さは $a\sqrt{2}$
- **平行と面積（等積変形）**
    - 底辺と高さが等しい三角形の面積は等しい。
    - 平行線にはさまれた三角形は、底辺が等しければ面積が等しくなります。

### 相似な図形
- **三角形の相似条件**
    - 3組の辺の比がすべて等しい。
    - 2組の辺の比とその間の角がそれぞれ等しい。
    - 2組の角がそれぞれ等しい。
- **相似比と面積比・体積比**
    - 相似比が $m : n$ のとき、面積比は $m^2 : n^2$、体積比は $m^3 : n^3$
- **中点連結定理**
    - $MN \parallel BC$、$MN = \frac{1}{2}BC$
    - 2辺の中点を結ぶ線分は、残りの辺に平行で、長さはその半分です。

### 円
- **円周角の定理**: 円周角は、同じ弧に対する中心角の半分です。
    - 同じ弧に対する円周角はすべて等しい。
- **直径に対する円周角**: 直径に対する円周角は $90^\circ$ です。
- **接線の性質**: 接点を通る半径は接線と垂直です。円外の1点から引いた2本の接線の長さは等しい。
- **円に内接する四角形**
    - 対角の和は $180^\circ$ です。逆に、対角の和が $180^\circ$ ならば円に内接します。
- **トレミーの定理 <span class="tag-maniac">マニアック</span>**
    - 円に内接する四角形ABCDについて、$AC \times BD = AB \times CD + AD \times BC$（対角線の積 = 2組の対辺の積の和）

### 空間図形
- **角柱・円柱の体積**
    - $V = Sh$（$S$は底面積、$h$は高さ）
- **角錐・円錐の体積**
    - $V = \frac{1}{3}Sh$（$S$は底面積、$h$は高さ）
- **球の体積**
    - $V = \frac{4}{3}\pi r^3$（$r$は半径）
- **球の表面積**
    - $S = 4\pi r^2$（$r$は半径）
- **表面積**: 角柱・円柱は 側面積＋底面積×2、角錐・円錐は 側面積＋底面積 で求めます。

### 面積の公式
- **三角形**
    - $S = \frac{1}{2}ah$（$a$は底辺、$h$は高さ）
- **平行四辺形**
    - $S = ah$（$a$は底辺、$h$は高さ）
- **ひし形**
    - $S = \frac{1}{2}mn$（$m, n$は対角線の長さ）
- **台形**
    - $S = \frac{1}{2}(a+b)h$（$a$は上底、$b$は下底、$h$は高さ）
- **円**
    - $S = \pi r^2$（$r$は半径）
- **円周の長さ**
    - $l = 2\pi r$（$r$は半径）

### 三平方の定理
- 直角三角形の斜辺を $c$、他の2辺を $a, b$ とすると
    - $a^2 + b^2 = c^2$
- **特別な直角三角形**
    - 直角をはさむ2辺が等しい直角三角形の辺の比は $1 : 1 : \sqrt{2}$（$45^\circ, 45^\circ, 90^\circ$）
    - $30^\circ, 60^\circ, 90^\circ$ の直角三角形の辺の比は $1 : \sqrt{3} : 2$
- **直方体の対角線**
    - 縦 $a$、横 $b$、高さ $c$ の直方体の対角線の長さは $\sqrt{a^2 + b^2 + c^2}$

## 関数

### 比例と反比例
- **比例**
    - $y = ax$（$a$は比例定数）
    - グラフは原点を通る直線です。
- **反比例**
    - $y = \frac{a}{x}$（$a$は比例定数）
    - グラフは双曲線です。

### 一次関数
- **一次関数**
    - $y = ax + b$（$a$は傾き、$b$は切片）
    - グラフは直線です。
- **変化の割合**
    - $\frac{yの増加量}{xの増加量}$
    - 一次関数では常に一定で、傾き $a$ に等しくなります。
- **2直線の交点**: 2つの式を連立方程式として解いて求めます。
- **平行条件**: 傾きが等しい2直線は平行です（$y = ax + b$ と $y = ax + b'$）。

### 二次関数
- **関数 $y = ax^2$**
    - グラフは原点を通る放物線です。$a > 0$ で下に凸、$a < 0$ で上に凸になります。
- **変化の割合**: 区間ごとに $\frac{yの増加量}{xの増加量}$ で計算します（一定ではありません）。
    - $y = ax^2$ の、$x$ が $p$ から $q$ まで変化するときの変化の割合は $a(p+q)$ です。
- **変域**: $y = ax^2$ の $y$ の変域は、$x = 0$ を含む場合に最小値（または最大値）が $0$ になります。

## 資料の活用と確率

### 代表値
- **平均値**
    - $\text{平均値} = \frac{\text{データの値の合計}}{\text{データの個数}}$
- **中央値（メジアン）**: データを大きさの順に並べたときの、ちょうど真ん中の値です（偶数個のときは中央の2つの平均）。
- **最頻値（モード）**: データの中で最も多く出てくる値です。

### 範囲と四分位数
- **範囲**: 最大値 − 最小値
- **四分位数**: データを小さい順に4等分する区切りの値です（第1四分位数・第2四分位数＝中央値・第3四分位数）。
- **四分位範囲**: 第3四分位数 − 第1四分位数
- **箱ひげ図**: 最小値・第1四分位数・中央値・第3四分位数・最大値を箱と線で表した図です。

### 度数分布
- **相対度数**
    - $\text{相対度数} = \frac{\text{その階級の度数}}{\text{度数の合計}}$
- **累積度数**: ある階級までの度数の合計です。
- **ヒストグラム**: 階級ごとの度数を柱状で表したグラフです。

### 近似値と有効数字
- **近似値**: 実際の値に近い値です。測定値は近似値です。
- **誤差**: 近似値 − 実際の値
- **有効数字**: 測定値のうち信頼できる数字です。有効数字 $n$ 桁で表します（例: $2.5 \times 10^3$ は有効数字2桁）。

### 標本調査
- **全数調査**: 対象全体（母集団）をすべて調べることです。例: 国勢調査
- **標本調査**: 母集団から一部（標本）を取り出して調べ、全体の傾向を推測することです。例: テレビの視聴率調査
- **標本の大きさ**: 標本として取り出す個数です。大きいほど、母集団に近い結果が得られます。

### 確率
- **確率の定義**: すべての結果が同様に確からしいとき
    - $\text{確率} = \frac{\text{そのことがらが起こる場合の数}}{\text{起こりうるすべての場合の数}}$
- **樹形図**: 場合の数を数え上げる図で、数え漏れを防ぎます。
- **確率の範囲**: $0 \le P \le 1$
- **排反な事象の確率（和の法則）**
    - $P(A \text{または} B) = P(A) + P(B)$
    - 同時に起こらない（排反な）事象A, Bに対して成り立ちます。
- **余事象の確率**
    - $P(\bar{A}) = 1 - P(A)$
