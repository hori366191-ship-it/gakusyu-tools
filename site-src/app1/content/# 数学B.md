# 数学B

## 数列

### 等差数列と等比数列
- **等差数列の一般項**
    - $a_n = a+(n-1)d$　
      初項a、公差dの等差数列の第n項を求めます。
- **等差数列の和**
    - $S_n = \frac{1}{2}n(a+l)$
    - $S_n = \frac{1}{2}n\\{2a+(n-1)d\\}$
- **等比数列の一般項**
    - $a_n = ar^{n-1}$　
      初項a、公比rの等比数列の第n項を求めます。
- **等比数列の和**
    - $S_n = \frac{a(r^n-1)}{r-1} = \frac{a(1-r^n)}{1-r} \quad (r \ne 1)$

### 様々な数列
- **自然数の累乗の和**
    - $\sum_{k=1}^{n} k = \frac{1}{2}n(n+1)$
    - $\sum_{k=1}^{n} k^2 = \frac{1}{6}n(n+1)(2n+1)$
    - $\sum_{k=1}^{n} k^3 = \\{\frac{1}{2}n(n+1)\\}^2$
- **$\Sigma$の性質**
    - $\sum_{k=1}^{n} (a_k \pm b_k) = \sum_{k=1}^{n} a_k \pm \sum_{k=1}^{n} b_k$
    - $\sum_{k=1}^{n} pa_k = p \sum_{k=1}^{n} a_k$
- **階差数列**
    - $a_n = a_1 + \sum_{k=1}^{n-1} b_k \quad (n \ge 2)$　
      数列の隣り合う項の差が作る数列（階差数列$b_n$）を利用して、元の数列の一般項$a_n$を求めます。
- **数列の和と一般項の関係**
    - $a_1 = S_1$
    - $a_n = S_n - S_{n-1} \quad (n \ge 2)$
- **部分分数分解の和**
    - $\frac{1}{k(k+m)} = \frac{1}{m}\left(\frac{1}{k}-\frac{1}{k+m}\right)$ を利用すると、途中の項が消えて和が求められます。
    - 例: $\sum_{k=1}^{n}\frac{1}{k(k+1)} = 1-\frac{1}{n+1}$

### 群数列
- **群数列の考え方**: 数列を $1, 2, 3, \dots$ 個ずつの「群」に分けて考える方法です。
    - 例: $1 \mid 2, 3 \mid 4, 5, 6 \mid 7, 8, 9, 10 \mid \cdots$
- **第n群の最初の項の番号**
    - 第1群から第n-1群までの項数の合計 + 1
    - 各群の項数が $1, 2, 3, \dots$ の場合、$\frac{n(n-1)}{2}+1$
- **第n群の末尾の項の番号**
    - 第1群から第n群までの項数の合計（各群の項数が $1, 2, \dots, n$ なら $\frac{n(n+1)}{2}$）
- **解き方の手順**
    1. 各群の項数の規則を確認する。
    2. 指定された項が「第何群の何番目」かを計算する。
    3. 群の総和は、等差数列・等比数列の和の公式を利用する。

### 漸化式
- **基本的な漸化式**
    - $a_{n+1} = a_n+d \implies \text{等差数列}$
    - $a_{n+1} = ra_n \implies \text{等比数列}$
    - $a_{n+1} = a_n+(nの式) \implies \text{階差数列}$
    - **$a_{n+1} = pa_n+q$ 型**
    - 特性方程式 $\alpha=p\alpha+q$ を利用して、$a_{n+1}-\alpha = p(a_n-\alpha)$ の形に変形し、等比数列に帰着させます。
- **$pa_{n+2}+qa_{n+1}+ra_n=0$ 型**
    - 特性方程式 $px^2+qx+r=0$ の解を利用して、等比数列の形に帰着させます。
- **$a_{n+1}=pa_n+q^n$ 型**
    - 両辺を $p^{n+1}$ で割って、$\frac{a_n}{p^n}$ を新しい数列として扱います。
- **連立漸化式**
    - $a_{n+1}=pa_n+qb_n$、$b_{n+1}=ra_n+sb_n$ の形は、辺々加減して等比数列を作るか、特性方程式で解きます。
- **分数型漸化式 <span class="tag-maniac">マニアック</span>**
    - $a_{n+1}=\frac{pa_n+q}{ra_n+s}$ の形は、特性方程式 $x=\frac{px+q}{rx+s}$ の解を利用して変形します。

### 数学的帰納法
- 自然数nに関する命題を証明する手法です。
    1. **[1]** n=1のときに命題が成り立つことを示す。
    2. **[2]** n=kのときに成り立つと仮定すれば、n=k+1のときも成り立つことを示す。

## 統計的な推測

### 確率変数と確率分布
- **期待値 (平均)**
    - $E(X) = m = \sum_{k=1}^{n} x_k p_k$　
      確率変数がとるであろう値の平均的な大きさを示します。
- **分散**
    - $V(X) = E((X-m)^2) = \sum_{k=1}^{n} (x_k-m)^2 p_k$　
      確率変数の値が、その期待値からどれだけ散らばっているかの度合いを示す指標です。
- **分散の公式**
    - $V(X) = E(X^2)-\\{E(X)\\}^2$　
      「Xの2乗の期待値」から「Xの期待値の2乗」を引くことで、分散をより簡単に計算できます。
- **標準偏差**
    - $\sigma(X) = \sqrt{V(X)}$　
      分散の正の平方根で、期待値からの散らばり具合を元のデータと同じ単位で表します。

### 確率変数の変換と独立性
- **確率変数の変換** ($Y = aX+b$ のとき)
    - $E(Y) = aE(X)+b$
    - $V(Y) = a^2V(X)$
    - $\sigma(Y) = |a|\sigma(X)$
- **確率変数の和と積**
    - $E(X+Y) = E(X)+E(Y)$
    - $E(aX+bY) = aE(X)+bE(Y)$
    - X, Yが互いに独立であるとき:
        - $E(XY) = E(X)E(Y)$
        - $V(X+Y) = V(X)+V(Y)$
        - $V(aX+bY) = a^2V(X)+b^2V(Y)$

### 代表的な確率分布
- **二項分布 $B(n, p)$**
    - **確率**: $P(X=r) = {}_nC_r p^r q^{n-r} \quad (q=1-p)$　
      互いに独立な試行をn回繰り返すとき、確率pで起こる事象がr回起こる確率を示します。
    - **期待値・分散・標準偏差**:
        - $E(X) = np$
        - $V(X) = npq$
        - $\sigma(X) = \sqrt{npq}$
- **正規分布 $N(m, \sigma^2)$**
    - **確率密度関数**: $f(x)=\frac{1}{\sqrt{2\pi}\sigma}e^{-\frac{(x-m)^2}{2\sigma^2}}$　
      平均m、標準偏差σの連続的なデータの分布を表す、釣り鐘型の曲線です。
- **標準正規分布 $N(0, 1)$**
    - $Z=\frac{X-m}{\sigma}$　
      正規分布に従う確率変数Xを、平均が0、標準偏差が1になるように標準化する変換です。
- **二項分布の正規近似**
    - $n$ が大きいとき、$B(n,p)$ は $N(np, npq)$ で近似できます（目安: $np \ge 5$）。
    - 連続修正: $P(X=r)$ は $r-0.5 \le X \le r+0.5$ の範囲の確率として近似します。

### 標本と推定
- **標本平均の期待値と標準偏差**
    - $E(\bar{X}) = m$
    - $\sigma(\bar{X}) = \frac{\sigma}{\sqrt{n}}$　
      母集団から抽出した標本の平均$\bar{X}$の期待値は母平均mに、標準偏差は母標準偏差$\sigma$を標本の大きさnの平方根で割ったものに等しくなります。
- **母平均の推定** (信頼度95%の信頼区間)
    - $[\bar{X}-1.96\frac{\sigma}{\sqrt{n}}, \bar{X}+1.96\frac{\sigma}{\sqrt{n}}]$　
      標本平均$\bar{X}$を用いて、未知の母平均mが95%の確率で含まれると推定される範囲です。
- **母比率の推定** (信頼度95%の信頼区間)
    - $[R-1.96\sqrt{\frac{R(1-R)}{n}}, R+1.96\sqrt{\frac{R(1-R)}{n}}]$　
      標本比率Rを用いて、未知の母比率pが95%の確率で含まれると推定される範囲です。

### 仮説検定
- **仮説検定の流れ**: 帰無仮説を立てる → 有意水準（通常5%）を定める → 棄却域を求める → 判断します。
- **片側検定と両側検定**: 有意水準5%の両側検定では、標準化した統計量が $|Z| \ge 1.96$ の領域を棄却域とします。
- **検定の判断**: 検定統計量が棄却域に入れば帰無仮説を棄却し、入らなければ棄却しない（=棄却できない）と判断します。
