# RSI — 再帰的自己改善

AIがAIの開発を改善する再帰ループを、**現在の実装**と**未実証の仮説**に分けて学ぶ静的3D展示です。`その他/frontier-atlas/`（Starship）と `その他/frontier-atlas-space-dc/`、`site/`、ポータル、GAS、既存アプリは変更していません。

## ローカル起動

ES Modulesとimport mapを使うため、`file://` ではなくHTTPサーバーで開きます。PowerShellでこのフォルダを作業ディレクトリにして実行します。

```powershell
python -m http.server 8080
```

ブラウザで `http://localhost:8080/` を開きます。Three.js 0.180.0はjsDelivrのCDNから読み込みます。CDNやWebGLが利用できない場合、WebGLコンテキストを失った場合は、インラインSVGの2D模式図と解説へ安全に切り替わります。外部API・バックエンド・認証・画像・3Dモデルファイルは使いません。

## 操作

- 上部の「現在のAI支援 / 完全自律RSI（仮説）」で、実装と仮説を切替
- 左の構成要素または3Dラベルで、コード生成・実験・評価・モデル改善を選択
- 再生 / 一時停止、0.5× / 1× / 2×、視点リセット、ズーム
- ドラッグまたは矢印キーで周回、ホイール・ピンチ・`+` / `-`でズーム
- `Space`で再生 / 一時停止、`R`で視点リセット
- 「自動化の範囲 / 評価の信頼性 / 人間の監督」を調整
- モバイルでは右の解説パネルを開閉

`prefers-reduced-motion: reduce` では自動再生しません。ページが非表示の間は描画を止め、再表示時にフレーム時刻をリセットします。

## 方向とモード構造

- `FLOW_DIRECTION` を状態層で共有し、外周の矢印・粒子・fallback粒子・現在ノード表示を同じ順序に統一しています。
- 放射粒子は、コアからノードへ進むシアンと、ノードからコアへ戻る紫を別色で表示します。
- **現在のAI支援**は、評価 → 人間レビュー → モデル改善の承認ゲートを通る開ループです。監督リングは濃く、`HUMAN IN THE LOOP` を表示します。
- **完全自律RSI（仮説）**は、モデル改善 → コード生成へ戻る閉ループです。内側の第2再帰リングと `生成N → 生成N+1` を表示し、監督リングは細く点滅させます。
- モード切替時は、承認ゲートの消失・内側リングの出現・色変化をモーフで表示します。

## 機械的な3Dモデル

- 多層半球シェル、内部回路基板、演算ユニット、ジャイロスコープ環、ガラス外殻、光ファイバー/ケーブルを持つAIコア
- code: 基板・チップ・ピン・回路トレース・コード粒子
- experiment: 試験管・ロボットアーム・計測リング・試料粒子
- evaluation: 走査リング・独立テスト柱・判定ゲージ
- model: 積層ニューラルネットワーク・結晶・世代交代コア
- ホログラム床、遠方星雲、浮遊演算モジュール
- PBR、半透明、加法発光を使い分け、`InstancedMesh`と自動品質調整で軽量化

モデルは学習用の模式図であり、実際のAIアーキテクチャや実行系を再現したものではありません。モバイルでは品質を落としても主要シルエットを維持します。

## 何を学ぶページか

- RSIは、AIが自らの改善に寄与し、その改善が次のAI開発へつながる考え方です。
- 現在のAI支援には、コード生成、プロンプト改善、実験提案、データ分析、モデル評価を含めます。
- RAND 2026の報告の要点として、AIはAI研究・開発の有意義な部分をすでに自動化していますが、公開情報では自分の研究アジェンダを設定したり後継モデルを設計したりするシステムは確認されていません。
- 自己目標設定、自己 redesign、知能爆発は未実証の仮説です。実現・速度・安全性を断定しません。
- 評価の信頼性、目標のずれ、評価ハック、内部セキュリティ、監督の遅れ、loss of controlを課題として扱います。
- スライダーは「自動化が評価・監督を追い越すと危険が増す」という因果関係を体験するための教育用概念モデルです。**実際の事故確率・知能の測定・将来予測ではありません。**

## ファイル

- `index.html` / `app.css` — UI、レスポンシブ表示、操作、SVGフォールバック
- `app.mjs` — 再生・モード切替・スライダー・動的import・安全停止
- `content.mjs` — 実装 / 仮説、構成要素、課題、出典
- `loop-state.mjs` — 純粋な概念モデル、進行方向、開閉ループ、放射粒子
- `rsi-model.mjs` — 自作プロシージャル3Dモデルと構造モーフ
- `rsi-viewer.mjs` — Three.js描画、カメラ、投影ラベル、星雲・床・浮遊モジュール
- `favicon.svg`
- `../../scripts/tests/frontier-rsi.test.cjs` — Node回帰テスト（リポジトリ側）

## 確認コマンド

```powershell
node --check app.mjs
node --check content.mjs
node --check loop-state.mjs
node --check rsi-model.mjs
node --check rsi-viewer.mjs
node --test ../../scripts/tests/frontier-rsi.test.cjs
```

テストは方向と接線の一致、開閉ループ、放射粒子の色、最小文字サイズ、静的な戻り値契約、Three.js構造スタブによるランタイム生成/updateを検証します。ブラウザでの最終操作・描画確認は別のtestサブエージェントの担当です。
