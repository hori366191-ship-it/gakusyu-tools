# FRONTIER ATLAS — ローカル索引

生命・エネルギー・AI/情報・宇宙・化学の全16項目を分野別に並べた、ダーク展示風のローカル索引ページです。既存アプリや新規アプリのディレクトリは変更しません。

## ローカル起動

リポジトリルートで8084番ポートを配信します。

```powershell
python -m http.server 8084 --bind 127.0.0.1
```

ブラウザで次のURLを開きます。

`http://127.0.0.1:8084/その他/frontier-atlas-hub/`

## リンク契約

| 項目 | 状態 | リンク先 |
|---|---|---|
| Starship | 既存 | `http://127.0.0.1:8080/` |
| RSI | 既存 | `http://127.0.0.1:8081/` |
| 宇宙データセンター | 既存 | `http://127.0.0.1:8082/` |
| Blender比較（補助リンク） | 既存 | `http://127.0.0.1:8083/その他/frontier-atlas-blender/` |
| 新規13項目 | 新規 | `../frontier-atlas-<slug>/` |

新規リンクはhubから見た兄弟ディレクトリを指します。個別アプリがまだ配置されていない段階では、そのリンク先は404になります。研究段階は分野全体の大まかな分類であり、個別ページ内で実績・計画・仮説を分ける前提の索引です。

## 実装

- `index.html` — 5分野・16カード、分野ナビゲーション、既存展示へのリンク
- `app.css` — ダーク展示風の配色、カードグリッド、レスポンシブ表示、フォーカス表示
- `favicon.svg` — 索引専用の六角形マーク
- `README.md` — 起動方法とリンク契約

`app.mjs` は任意のため未使用です。ページは静的なHTML/CSSだけで動作し、外部API・外部フォント・CDN・トラッキングは使いません。本文は15px以上を基準にし、モバイルでは1列表示へ切り替えます。

## 確認コマンド

リポジトリルートで実行します。

```powershell
node --check "scripts/tests/frontier-hub.test.cjs"
node --test "scripts/tests/frontier-hub.test.cjs"
```

テストは16カード、分野とslugの対応、既存/新規の状態、4種類の外部リンク契約、新規リンクの相対パス、日本語・レスポンシブ・ローカル表示の基本契約を検証します。ブラウザでの最終操作・描画確認は別のtestサブエージェントの担当です。
