01 / SYSTEM OVERVIEW

宇宙で計算する仕組み

太陽光発電、AI計算、衛星間の光通信、赤外線による放熱を組み合わせ、処理結果を地球へ送ります。どこか一つだけの技術ではなく、系全体の設計が重要です。

まずは地上データセンターの完全な代替ではなく、宇宙で集まるデータを近くで処理する軌道上エッジ処理が現実的です。

データとエネルギーの流れ SYSTEM FLOW

  1. 01

    太陽光を集める広い太陽電池で電力を確保

  2. 02

    軌道上で計算AIアクセラレータがデータを処理

  3. 03

    光でつなぐ衛星間でデータを中継

  4. 04

    地球へ返す必要な結果だけを地上局へ送信

      操作方法

        実証と構想を区別する

        Starcloud-1は2025年11月にH100を搭載して打ち上げられ、2025年12月に小型LLMの推論・学習を実施したと企業が発表しました。これは大規模宇宙データセンターの完成ではなく、軌道上計算の小さな実証です。

        Google Project Suncatcherは、太陽光発電衛星群、TPU、自由空間光通信を使うスケーラブルなAIインフラの研究構想です。地上データセンターを完全に置き換えるものではなく、まず軌道上エッジ処理が現実的な用途です。

        正確さと出典

        地球表面はapp13のNASA Blue Marble: Next Generation（2004年7月）テクスチャを使い、回転を停止しています。雲・大気・衛星・地球局はコード生成の教育用模式図です。軌道・通信速度・温度・時間は実際の設計値を再現していません。
