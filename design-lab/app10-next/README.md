## 3つの探し方

- **鎖式**: 分子全体の総炭素数（–COOH・–COO–・–C≡N などの官能基炭素を含む）＋化合物分類＋構造条件（飽和鎖式 / 不飽和鎖式 / すべて）。飽和は C=C・C≡C を含まない鎖式で、C=O は不飽和炭素結合として数えません。アルコールは**一価アルコール**と**多価アルコール**を別分類にし、OH数と飽和/不飽和を独立軸として扱います。C3の飽和一価アルコールはプロパン-1-オール＋プロパン-2-オールの2件、飽和多価アルコールはグリセリン＋プロピレングリコールの2件です。アミンは第一級〜第三級の一般構造を常時表示し、該当しない級は「条件不足」と明記します。C2アミンはエチルアミン＋ジメチルアミン、C3アミンはプロパン-1-アミン＋プロパン-2-アミン＋エチルメチルアミン＋トリメチルアミンを表示します。エーテルは C2 ジメチルエーテル、C3 メトキシエタン、C4 3種（ジエチルエーテル・1-メトキシプロパン・2-メトキシプロパン）を表示します。
- **芳香族・環式**: ベンゼン・ナフタレン・シクロアルカン・シクロヘキセン・アントラセンなどの固定骨格を選び、環のHを置換基で置き換えます。多置換体（p-ジクロロベンゼン、キシレン、クレゾール、TNT、ピクリン酸など）は一置換生成に混ぜず、別familyとして表示します。
- **その他**: 糖類・アミノ酸/タンパク質/酵素・脂質・天然高分子・合成高分子・材料/混合物・有機塩・染料のcategory→familyで選び、複数の物質・family・材料をまとめて表示します。単一の固定分子式をもたない酵素・リン脂質・高分子・再生セルロースなどは、純物質カードに偽装しません。

「C–C結合を保つ表記ではありません」「実際の合成手順ではありません」を鎖式・エーテルの説明に明記しています。
