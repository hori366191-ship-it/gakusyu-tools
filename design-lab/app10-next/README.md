## 3つの探し方

- **鎖式**: ①官能基に結合する**炭化水素部分**の炭素数と骨格（つながり方・分かれ方）、②化合物分類の順に選びます。総炭素数と飽和/不飽和の選択は廃止し、①のC数は「分子全体C－カルボニルC（C=O）－ニトリルC（C≡N）」で数えます（OHをもつ炭素は炭化水素部分に残す）。①の選択カードは「上段=簡単な構造（文字式または小さな構造図）／下段=名前（○○由来・○○基×n）」に統一し、選択後の①プレビューは原子とHを明示した構造式で表示します（メタンCH₄の4H、エタンC₂H₆の6H、プロパンC₃H₈の8H、ネオヘキサンの四級炭素と枝）。接続点にHを補った親炭化水素であることを保持します。複数fragmentは接続点のダッシュで分け、独立部分間に結合線を描きません（例: CH₃−　−CH₃＋「メチル基×2」）。長い直鎖だけは `CH₃(CH₂)ₙCH₃` の繰返しで圧縮し、その旨を注記します。C0は「炭化水素部分なし」とし、Hが結合する場合（ギ酸・ホルムアルデヒドのR=H）と官能基どうしが直接結合する場合（シュウ酸）を別shapeに分けます。`d-h-c0` と `d-direct-c0` はH親図に一括偽装しません。②は一般の官能基fragmentと分類だけを表示し、①を書き換えません。②が①の変更で無効になった場合だけ分類を解除し、有効なら維持します。①のC数を変えて骨格が無効になった場合は、別の骨格へ自動で飛ばさず「骨格の形を選んでください」と表示します。初期値はC2・エタン由来・アルカンです。分類の並びはアルカン→アルケン→アルキン→ハロゲン化物→アルコール（一価）→多価アルコール→エーテル→アルデヒド→ケトン→カルボン酸→無水物→エステル→アミン→ニトリル→ニトロ→アミノアルコールです。炭素の点線circle・○凡例は表示せず、接続点metadataは内部mappingにだけ保持します。C0だけを炭素gridのfull-rowにし、他のCボタンの列数は変えません。
- **芳香族・環式**: ベンゼン・ナフタレン・シクロアルカン・シクロヘキセン・アントラセンなどの固定骨格を選び、②「置換基・組み合わせ」から**学習用プリセット**を1回選びます。見出しは「置換基1つ」「同じ置換基を複数」「異なる置換基組み合わせ」で、たとえば OH はフェノールのみ、CH₃ はトルエン、OH×2 はカテコール・レゾルシノール・ヒドロキノン、CH₃×2 は3種のキシレン、OH＋COOH はサリチル酸・m-/p-ヒドロキシ安息香酸、OH＋CH₃ は3種のクレゾール、COOH＋OCOCH₃ はアスピリンを、同じ位置異性体のまとまりとして結果に表示します。置換基の種類・数・位置は `ring-sub.subs` と custom 用の `RING_SUBS` metadata で定義し、名前の部分一致では判定しません。「追加なし」は固定骨格単体（ベンゼンならベンゼン1件、ナフタレンならナフタレン1件）だけを表示し、登録済みの単置換体・多置換体はプリセットまたは「その他の登録済み化合物」の受け皿から到達できます。塩・複雑な置換基は既存の有機塩・材料の扱いを維持します。
- **その他**: 糖類・アミノ酸/タンパク質/酵素・脂質・天然高分子・合成高分子・材料/混合物・有機塩・染料のcategory→familyで選び、複数の物質・family・材料をまとめて表示します。単一の固定分子式をもたない酵素・リン脂質・高分子・再生セルロースなどは、純物質カードに偽装しません。

「C–C結合を保つ表記ではありません」「実際の合成手順ではありません」を鎖式・エーテルの説明に明記しています。

## 構造式と簡略構造式の二重表示

- 結果カードは原則として「構造式」と「簡略構造式」を縦に併記し、さらに**文字で読める「簡略構造式: …」**を共通カードUIに表示します（例: エタノール `CH₃CH₂OH`、プロピレングリコール `CH₃CH(OH)CH₂OH`、グリセリン `HOCH₂CH(OH)CH₂OH`）。文字はコピーでき、長い式は折り返します。
- graph構造（skeleton / sub / multi / custom）は水素を明示した構造式と、炭素・水素を省略した骨格図を同じgraphから描きます。文字の簡略式は検証済みgraphまたは明示登録から作り、分子式だけ・物質名だけにはしません。環式で一意の縮合式を安全に作れないものは、文字を捏造せず図参照の注記にします。
- ring-subは `subs` の位置metadataから、明示された置換基表記（OH・CH₃・COOH・NH₂・OCOCH₃・SO₃H・N(CH₃)₂等）を原子グラフに組み、構造式＋簡略構造式を表示します（33件）。文字側は環の水素数と置換基から `C₆H₄(OH)(COOH)` のように表示します。
- condensedは、明示された結合記号（—・=・≡）と括弧だけを使い、分岐・環・電荷・原子価を検証したgraphだけを二重表示します。式から名前・立体・結合を推測しません。32件の誤接続（N-C-C-C、F主鎖、環消失等）は修正し、構造signature・結合価・環・N隣接をunitで固定しました。クメンヒドロペルオキシド（ベンゼン–C(CH₃)₂–O–O–H）、ビスフェノールA（2つのp-ヒドロキシフェニル–C(CH₃)₂）、アスパルテーム（HOOC–CH₂–CH(NH₂)–C(=O)–NH–CH(CH₂Ph)–C(=O)–OCH₃：Asp側鎖CH₂COOHは遊離、Aspのα-カルボキシルがPheアミノ基とペプチド結合、Pheカルボキシルはメチルエステル）も明示graph化しています。
- 塩は金属regexで一律排除せず、Na⁺・Ca²⁺・Pb²⁺・Ag⁺・Cu⁺等の対イオンと有機陰イオンを**結合でつながない電荷分離graph**で表示します（酢酸Na、Naメトキシド、Naエトキシド、Naフェノキシド、安息香酸Na、ラウリン酸Na等）。長鎖・多成分塩、複合染料は原子数/複合度の理由で簡略表示にします。
- 糖類はα/β/フィッシャー/ハースの投影式を維持し、文字側は「立体配置は図（投影式）が正本」と注記します。重合体・模式図・油脂は繰り返し単位・一般式・模式図のまま、一意の縮合式を作りません。
- 例外は「原子数閾値 40（水素を含む原子数）」「投影式」「重合体」「模式図」「油脂」「シス/トランス保持」「複合芳香族・複合塩/染料」の基準で、`figurePlan` / `figureAudit` と収録台帳に記録します。全リストは `catalog-audit.md` を参照してください。
- 図はカード内で2カラムを維持しつつ、SVGのviewBoxを原子・結合・H・電荷・文字幅の実内容bboxに合わせて余白を適正化します。モバイルでも全SVGへ `min-width: 400px` を強制せず、ページ・カード・図枠のどこにも横スクロールを作りません。長い簡略式は化学単位の区切りで複数行に折り返し、複雑な図はカード内で全体を縮小表示し、明示的な「拡大」ボタンからダイアログで読めます（閉じる・Escape・フォーカス復帰・スクロール位置復元に対応）。

## 選択カードの表示規則

- ①の骨格カードは全47shapeで「上段=簡単な構造／下段=名前」に統一します。単一fragmentの名前は `メタン由来 / エタン由来 / プロパン由来 / エテン由来 / エチン由来 / 2,2-ジメチルブタン由来` のように親炭化水素＋「由来」とし、`メチル基（メタン由来）` のような取り違えやすい慣用名を混在させません。分岐骨格はIUPAC名を主表示し、`ネオヘキサン` などの慣用名は別名として注記・検索で到達できます（物質レコードは重複追加しません）。
- 複数fragmentは `メチル基×2 / エチル基＋メチル基 / H＋プロピル基` のように「○○基×n／○○基＋△△基」で示します。接続位置を特定しない単一fragmentでも位置異性体の結果は保持し、`プロピル基` の1語でn-/イソプロピルの片方と誤認させません。
- 短い直鎖は `CH₄ / CH₃−CH₃ / CH₃−CH₂−CH₃ / CH₂=CH₂ / CH≡CH` の文字式、長い直鎖は `CH₃(CH₂)₄CH₃` の繰返しで圧縮します（この括弧は繰返しのため可）。分岐は文字括弧だけにせず、小さな2D構造図で枝を見せます。選択後の①プレビューは別表示で、C6以下は原子とHをすべて明示した構造式、C7以上は縮約式＋注記です。
- ②の鎖式分類カードは全16分類で「上段=官能基の簡単な形（−OH / −O− / −CHO / −CO− / −COOH / −COO− / −C≡N / −CO−O−CO− / −NO₂ / −X / C−C / C=C / C≡C など）／下段=分類名」に統一します。選択カードでは `C(=O)` の括弧表記を使わず、詳しい右previewでは実際の二重結合線でC=O・C≡Nを描きます。アミンは `−NH₂ など` として第二・第三級を排除したと誤認させず、右previewで1〜3級の一般形を保持します。C1アルカンは `C−C` を要求せず `CH₄` と表示します。
- 環式②のカードも「上段=置換基fragment／下段=置換基名」とし、複数置換基の種類と数を示します。「追加なし」は `追加なし／骨格単体のみ` と説明し、ベンゼン環の図を出しません（環の図は①の固定骨格側だけ）。
- 「鎖式／芳香族・環式／その他」のモードボタンは320px・390px・1280pxのいずれでも3列（`repeat(3, minmax(0, 1fr))`）を維持し、主ラベル大・補足小のまま、`芳香族・環式` は折り返し可能、タップ領域は44px以上を確保します。①の左右2列と結果カードの2列は別レイアウトとして維持します。
