## 3つの探し方

- **鎖式**: ①官能基に結合する**炭化水素部分**の炭素数と骨格（つながり方・分かれ方）、②化合物分類の順に選びます。総炭素数と飽和/不飽和の選択は廃止し、①のC数は「分子全体C－カルボニルC（C=O）－ニトリルC（C≡N）」で数えます（OHをもつ炭素は炭化水素部分に残す）。①は「エタン由来 / エテン由来 / エチン由来 / メチル基×2 / H＋メチル基」のような親炭化水素の語彙で、成分を役割非依存にcanonical dedupeします。エステルのacyl/alkoxyは①では分けず、結果カードの構造・式・役割badgeで区別します。①の左には接続点にHを補った親炭化水素を表示し、接続点を○で示します。C0は「炭化水素基なし〈H〉」としてギ酸・ホルムアルデヒド・シュウ酸に対応します。②は一般の官能基fragmentと分類だけを表示し、①を書き換えません。②が①の変更で無効になった場合だけ分類を解除し、有効なら維持します。①のC数を変えて骨格が無効になった場合は、別の骨格へ自動で飛ばさず「骨格の形を選んでください」と表示します。初期値はC2・エタン由来・アルカンです。分類の並びはアルカン→アルケン→アルキン→ハロゲン化物→アルコール（一価）→多価アルコール→エーテル→アルデヒド→ケトン→カルボン酸→無水物→エステル→アミン→ニトリル→ニトロ→アミノアルコールです。
- **芳香族・環式**: ベンゼン・ナフタレン・シクロアルカン・シクロヘキセン・アントラセンなどの固定骨格を選び、②「置換基・組み合わせ」から**学習用プリセット**を1回選びます。見出しは「置換基1つ」「同じ置換基を複数」「異なる置換基組み合わせ」で、たとえば OH はフェノールのみ、CH₃ はトルエン、OH×2 はカテコール・レゾルシノール・ヒドロキノン、CH₃×2 は3種のキシレン、OH＋COOH はサリチル酸・m-/p-ヒドロキシ安息香酸、OH＋CH₃ は3種のクレゾール、COOH＋OCOCH₃ はアスピリンを、同じ位置異性体のまとまりとして結果に表示します。置換基の種類・数・位置は `ring-sub.subs` と custom 用の `RING_SUBS` metadata で定義し、名前の部分一致では判定しません。「追加なし」は固定骨格単体（ベンゼンならベンゼン1件、ナフタレンならナフタレン1件）だけを表示し、登録済みの単置換体・多置換体はプリセットまたは「その他の登録済み化合物」の受け皿から到達できます。塩・複雑な置換基は既存の有機塩・材料の扱いを維持します。
- **その他**: 糖類・アミノ酸/タンパク質/酵素・脂質・天然高分子・合成高分子・材料/混合物・有機塩・染料のcategory→familyで選び、複数の物質・family・材料をまとめて表示します。単一の固定分子式をもたない酵素・リン脂質・高分子・再生セルロースなどは、純物質カードに偽装しません。

「C–C結合を保つ表記ではありません」「実際の合成手順ではありません」を鎖式・エーテルの説明に明記しています。

## 構造式と簡略構造式の二重表示

- 結果カードは原則として「構造式」と「簡略構造式」を縦に併記し、さらに**文字で読める「簡略構造式: …」**を共通カードUIに表示します（例: エタノール `CH₃CH₂OH`、プロピレングリコール `CH₃CH(OH)CH₂OH`、グリセリン `HOCH₂CH(OH)CH₂OH`）。文字はコピーでき、長い式は折り返します。
- graph構造（skeleton / sub / multi / custom）は水素を明示した構造式と、炭素・水素を省略した骨格図を同じgraphから描きます。文字の簡略式は検証済みgraphまたは明示登録から作り、分子式だけ・物質名だけにはしません。環式で一意の縮合式を安全に作れないものは、文字を捏造せず図参照の注記にします。
- ring-subは `subs` の位置metadataから、明示された置換基表記（OH・CH₃・COOH・NH₂・OCOCH₃・SO₃H・N(CH₃)₂等）を原子グラフに組み、構造式＋簡略構造式を表示します（33件）。文字側は環の水素数と置換基から `C₆H₄(OH)(COOH)` のように表示します。
- condensedは、明示された結合記号（—・=・≡）と括弧だけを使い、分岐・環・電荷・原子価を検証したgraphだけを二重表示します。式から名前・立体・結合を推測しません。32件の誤接続（N-C-C-C、F主鎖、環消失等）は修正し、構造signature・結合価・環・N隣接をunitで固定しました。クメンヒドロペルオキシド（ベンゼン–C(CH₃)₂–O–O–H）、ビスフェノールA（2つのp-ヒドロキシフェニル–C(CH₃)₂）、アスパルテーム（HOOC–CH₂–CH(NH₂)–C(=O)–NH–CH(CH₂Ph)–C(=O)–OCH₃：Asp側鎖CH₂COOHは遊離、Aspのα-カルボキシルがPheアミノ基とペプチド結合、Pheカルボキシルはメチルエステル）も明示graph化しています。
- 塩は金属regexで一律排除せず、Na⁺・Ca²⁺・Pb²⁺・Ag⁺・Cu⁺等の対イオンと有機陰イオンを**結合でつながない電荷分離graph**で表示します（酢酸Na、Naメトキシド、Naエトキシド、Naフェノキシド、安息香酸Na、ラウリン酸Na等）。長鎖・多成分塩、複合染料は原子数/複合度の理由で簡略表示にします。
- 糖類はα/β/フィッシャー/ハースの投影式を維持し、文字側は「立体配置は図（投影式）が正本」と注記します。重合体・模式図・油脂は繰り返し単位・一般式・模式図のまま、一意の縮合式を作りません。
- 例外は「原子数閾値 40（水素を含む原子数）」「投影式」「重合体」「模式図」「油脂」「シス/トランス保持」「複合芳香族・複合塩/染料」の基準で、`figurePlan` / `figureAudit` と収録台帳に記録します。全リストは `catalog-audit.md` を参照してください。
- 図はカード内で2カラムを維持しつつ、モバイルでは最小可読幅（400px）を確保して図枠内を横スクロールでき、明示的な「拡大」ボタンからダイアログを開けます（閉じる・Escape・フォーカス復帰・スクロール位置復元に対応）。

## 鎖式デスクリプタ（`chain-descriptor.js`）

- 鎖式154件すべてについて、`data.js` の構造から**検証済みの原子グラフ**を作り、`chain-descriptor.js` が炭化水素部分を導出します。graph化の内訳は build 80・condensedGraphFor 71・manual 3（maleic-acid / fumaric-acid / eicosane）です。分子式や名称から炭素骨格を推定しません。
- カルボニルC（C=O）とニトリルC（C≡N）はfunctional coreとして除外し、OHをもつ炭素は炭化水素部分に残します。O/N/ハロゲンなどの官能基原子を除いた炭素グラフの連結成分を、接続点にHを補った親炭化水素として扱います。
- C–Cの二重/三重結合は**結合位置を含めて**デスクリプタに保持します。exact tree canonicalは各頂点のelement/H/chargeと各edgeのbondorderを含み、root全頂点の最小符号で比較します。ブタ-1-エン / ブタ-2-エン、ブタ-1-イン / ブタ-2-イン、ペンタ-1-エン / ペンタ-2-エン、ペンタ-1-イン / ペンタ-2-インはそれぞれ別shape・別labelです。イソブテンも別骨格です。一方、Hを補うと同一の親炭化水素になるプロパン-1-オール / プロパン-2-オールは同じプロパン、ブタン-1-オール / ブタン-2-オールは同じブタン、イソブタノール類はイソブタンです。
- 成分のmultisetは役割非依存でcanonical dedupeし、同じcanonical signatureでは木の完全canonical符号で実同型も確認します（WL hashの衝突対策）。①の語彙は実測46件です。旧 `d-butene-c4` 等の誤統合shapeは削除し、focus付きURLはfocusの正確な新shapeへ、focusなしURLはnoticeで選び直します。
- 部分炭素数は「分子全体C－functional coreのC」で独立に照合します。例: トリアセチンは総C9－カルボニルC3＝**C6**（プロパン骨格＋メチル基×3）、ピルビン酸はC1、アジポイルクロリドはブタンC4、シュウ酸はC0です。
- カルボニルCに結合するHは、−CHOの固定HとR=Hを区別します。エタナール（CH₃CHO）・プロパナール（CH₃CH₂CHO）のCHO固定Hは①のH断片に数えず、①はそれぞれメチル・エチルです。ホルムアルデヒド（HCHO）はCHO固定H1以外のH1がR=Hなので①H（C0）、ギ酸（HCOOH）・ギ酸エステル（HCOOR）のcarbonyl C–HはR=Hとして①にH断片を残します。methyl+CHOとmethyl+COOHは同じ①メチル選択から②で選べます。
