# app10-concept — 有機化合物の「探し方」操作モック

`site/app10` や外部索引の調査とは独立した、画面・操作検討用の単体モックです。本番データ・ビルド・外部APIには依存しません。

## 開き方

`index.html` をブラウザで直接開く（ローカルサーバー不要）。

## 見せること

- **鎖式: 炭素数から探す** — 総炭素数（C2/C3）＋ 化合物分類（アミン/エーテル/アルコール）
  - 全鎖式共通で、総炭素数は固定骨格の指定ではなく、炭素の配分を比べる見方（合成反応ではない）と明示。
  - アミンは第一級/第二級/第三級の一般構造を常時表示。総炭素数2では第三級を「炭素数3以上で表示」と注記。
  - エーテルは R–O–R′ の炭素分配（C2: 1+1 / C3: 2+1）を表示。C–C 結合を保つ表記ではない旨を注記。
  - アミンは級ごと、それ以外は分類ごとに結果をまとめて表示（異性体の個別選択ボタンなし）。
- **芳香族: 骨格から探す** — ベンゼン環（環の炭素数6）を固定し、環Hを置換基（なし/−OH/−CH3）で置き換え。結果はベンゼン/フェノール/トルエン。トルエンは総炭素数7になるが、探し方は「固定した環と置換基」のまま。
- 操作のたびに右のプレビューと下の結果・件数・選択中条件を自動更新。

## 収録データ（モック用の最小限）

- 鎖式 C2/C3 のアミン・エーテル・アルコールのみ
- 芳香族はベンゼン環の3置換基のみ
- 構造描画ライブラリ・台帳・網羅データは持たない（ケクレ式はインラインSVG）

## 非対象

`site/`、`site/app10`、`site/themes`、本番の収録データ、外部索引の調査結果の変更は行いません。
