# 不規則動詞 一覧プリント（試作）

`design-lab/` 配下の試作。Pages 配信対象外（`site/` には影響しない）。

- `index.html` … 単体で完結（外部CDN・外部フォント・外部画像を読み込まない）。ブラウザで直接開けば確認できる。
- データ源は `docs/english-irregular-verbs.md` の「3. 基本 74語」「4. 発展 28語」の表。原形・過去形・過去分詞・意味・型を改変せずに HTML 内の `DATA` 配列へ転記している（`lv: 1` = 基本 / `lv: 2` = 発展）。
- 再生成するときは Markdown の表の行をそのまま貼り替え、`lv` を振り直す。**表記・並び順・型は原資料のまま**にする（詳細は `index.html` 冒頭コメント）。
- 紙面は **A4横（297×210mm）・1ページ3表（各5列）・全2ページ**。左の表 → 右へ → 次ページの順に流し込み、型グループの順序（A-A-A → A-B-A → A-B-B → A-B-C → A-A-B → その他）と型内アルファベット順を保つ。レイアウトは JS が列の高さを実測して自動で行い、収まる最大の文字サイズ（`STEPS`）を段階的に試す。用紙サイズや余白を変えたら、印刷プレビューで紙面からのはみ出しがないか確認する。
- 各行の先頭に通し番号（`#` 列）を 1〜102 で振る（基本1〜74 / 発展75〜102）。
- 原形・過去形・過去分詞の英単語は**太字（font-weight:700）**。その下にカタカナの発音（**6pt 前後・細字・左揃え**、目安）を置く。発音は `PRON`（キーは `DATA` の `b`）に持つ。意味は折返し可。

## 比較用ファイル（本番採用は `index.html` = 3表/ページ）

- `index-2tables.html` … 旧版（1ページ2表・発音は語の横に右揃え）。比較用に保存。
- `index-4tables.html` … 1ページ4表版。`?mode=4x5`（既定・5列）と `?mode=4x4`（意味列なし）を切り替え可能。
- `index.html` も `?mode=` を受け付ける（既定は `3x5`。`?mode=4x5` / `?mode=4x4` で4表版を比較できる）。
- `soft-card.html` … 試作A（カード型・横線のみ）。`soft-card-gap.html` … 試作A＋余白（型グループ見出しの直前に罫線・背景なしの空白行 1.6mm を追加）。`soft-minimal.html` … 試作Aの最小線版。
